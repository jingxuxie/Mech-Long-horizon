# How Long Is a Circuit Faithful?

**Temporal Scope, Relay Costs, and Fragile Cancellations**

Theory-first research on the temporal validity of executable mechanistic explanations. A circuit is a **persistent zero mask** of recurrent coordinates, not a hidden-state refresh or a newly trained replacement model.

## Completed in this version

- Full derivations in [`paper/main.tex`](paper/main.tex), including an exact nonnegative support theorem, shortest failure witnesses, a relay-cost separation, and a finite-radius obstruction to cancellation-dependent signed masks.
- Executable support certificates and an exact finite-state reference auditor in [`src/horizon`](src/horizon).
- **12,192** exhaustive mask/horizon checks: **2,976** masks in 60 random systems plus **9,216** controlled-curve cases; no support or shortest-witness disagreements.
- **12** rational-arithmetic mixed-difference checks, including reuse of the same recurrent coefficient across time; no bound violations.
- Ten trained, 16-unit tanh RNNs. Short-window selection exceeded tolerance 0.1 later in **6/10** seeds; long-window selection did not in these held-out tests. At a fixed size of 14 retained units, median maximum errors were **0.600** versus **0.183**.
- **24 passing tests**, raw per-seed results, experiment scripts, and figure-generation code.

The manuscript is a **working research draft**, not an independently reviewed or submission-ready claim. Novelty remains to be established against program slicing, model reduction, structural systems, formal circuit discovery, and recurrent windowed-ablation methods. The RNN results are empirical illustrations, not nonlinear certificates or matched-compute superiority claims. See [`docs/RESEARCH_STATUS.md`](docs/RESEARCH_STATUS.md).

## Central result

For a nonnegative switched linear system, initialize a declared set of source coordinates and specify allowed input/intervention sequences with a partial deterministic protocol automaton. In the product graph, let `d_in(i,q)` be the shortest distance from an initialized source and `d_out(i,q)` the shortest distance to an observable coordinate. Then

```text
birth(i) = min_q [d_in(i,q) + d_out(i,q)]
minimum_exact_mask(H) = {i : birth(i) <= H}
first_failure(K) = min_{i not in K} birth(i)
```

Two breadth-first searches compute every birth horizon after graph construction. Shortest paths give an explicit source and allowed intervention sequence witnessing failure. The graph algorithm is white-box and assumes nonnegative coefficients. A separate signed result requires independently perturbable structural coefficients; arbitrary nonlinear networks are not covered.

A delay-L chain illustrates an important distinction: only its first coordinate varies initially, so initial-state distinguishability requires one coordinate; a persistent exact subcircuit at horizon L needs **L+1** coordinates to transport that bit.

## Reproduce

Python 3.10+; CPU only. Core audit dependency: NumPy. Experiments also use PyTorch, matplotlib, and pytest.

```bash
python -m pip install -e '.[experiments]'
python -m pytest -q
python experiments/exact.py
python experiments/fragility.py
python experiments/trained_rnn.py --seeds 10 --steps 1000
python experiments/matched_size.py
python experiments/plots.py
```

The training script writes `results/rnn_seed0.json` through `rnn_seed9.json`; the matched-size experiment loads these checkpoints. Git contains source and raw measurements; checkpoints are regenerated by the command above and are also included in the accompanying downloadable research archive. Re-running experiments overwrites their corresponding result files.

To build the manuscript, first generate the figures, then use a LaTeX installation with natbib and standard mathematical packages:

```bash
cd paper
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main  # use bibtex8 main on systems without the bibtex alias
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

`make reproduce` runs the full experiment pipeline; `make paper` generates figures and builds the PDF. The source archive includes the compiled 15-page draft, five figures, and all ten checkpoints. Git intentionally tracks the regenerable text sources and measurements rather than binary build products.

## Evidence and scope

| Experiment | Evidence | Important limitation |
|---|---|---|
| Random support tests | Integer word enumeration vs graph theorem; independent witness replay | Small, nonnegative systems |
| Horizon curves | Exhaustive optimum over all masks | Designed mechanism families |
| Perturbation checks | Exact rational mixed differences | Not typical-noise sensitivity |
| Rare gate words | Analytic miss probability and 2,000 repeated audits per length | White-box graph access is stronger than random tests |
| Trained RNNs | Ten seeds; separate training, selection, and test streams | One synthetic task; no universal certificate |
| Same-size masks | Sizes 12, 14, and 15; 50 random masks per seed/size | Same cardinality, not matched compute |

The measured environment was Python 3.13.5, NumPy 2.3.5, PyTorch 2.10.0+cpu with one torch thread. The ten-seed training/primary evaluation took about 15.1 seconds and exact enumeration about 1.2 seconds in that environment. These are not runtime promises for another machine and exclude setup, writing, and literature review.
